# Mouse Highlighter（鼠标高亮工具）

一个轻量级的Windows鼠标位置高亮工具，帮助用户更容易地找到鼠标指针的位置，特别适合长时间使用电脑、视力不佳或需要演示操作的用户。

## 功能特性

- **实时高亮**：在鼠标周围显示可自定义的圆形高亮区域
- **高度可定制**：
  - 调整高亮半径（10px-150px）
  - 调节不透明度（20%-100%）
  - 自由选择高亮颜色
  - 可选是否显示中心红点
- **性能优化**：
  - 支持垂直同步（VSync），减少画面撕裂
  - 可调节目标帧率（30-200 FPS）
  - 高效渲染，低资源占用
- **便捷操作**：
  - 快捷键快速开关高亮效果
  - 实时显示当前帧率
  - 设置自动保存到INI配置文件

## 快捷键

- `Ctrl + F1`：打开/关闭设置窗口
- `Ctrl`：临时隐藏/显示高亮效果

## 配置说明

程序会在运行目录下生成 [mouse_highlighter.ini](file:///e:/Code/Where's_my_mouse/mouse_highlighter.ini) 文件保存所有个性化设置，包括：

- 高亮区域半径
- 不透明度
- 颜色值（RGB）
- 是否显示中心红点
- 垂直同步状态
- 目标帧率

## 编译要求

- Windows SDK（支持Windows Vista及以上版本）
- Visual Studio或其他支持编译Windows应用程序的开发环境
- C语言编译器

## 使用场景

- 长时间使用电脑导致视觉疲劳的用户
- 视力不佳，难以定位鼠标指针的用户
- 进行屏幕演示或教学的人员
- 需要精确跟踪鼠标移动的测试人员
- 任何希望提高鼠标可见性的用户

## 技术细节

- 使用Windows API实现原生性能
- 采用分层窗口技术实现透明效果
- 通过定时器和优化算法维持流畅动画
- 使用高性能计时器计算实际帧率

## 注意事项

- 程序会始终位于最顶层但不会抢占焦点
- 高帧率设置可能会增加CPU使用率
- 关闭VSync时请根据显示器刷新率合理设置目标帧率
